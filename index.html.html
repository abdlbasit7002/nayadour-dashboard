Enter one order per line, separated by commas:
OrderRef, Date(YYYY-MM-DD), Qty, SKU/Item, Amount, Status, Paid(yes/no), Tracking(optional), Comment(optional)
Example: ND#10050, 2026-07-02, 1, RIBBED TANK TOP M / BLACK, 1850, Delivered, no, 29246750006300, customer requested exchange
To import directly from a Google Sheet, first publish it to the web:
Open the sheet → File → Share → Publish to web → select your tab → format "Comma-separated values (.csv)" → Publish
Then paste the resulting link below. Columns should be in this order:
Order Ref, Tracking, Date, Qty, SKU, Amount, Paid, Returned, Exchange/Replacement, Comment
